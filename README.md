
# 🍽️ Swiggy Sales Data Analysis Dashboard

**Tech Stack:** Excel | Power BI

## 📌 Project Overview

This project presents a comprehensive analysis of **Swiggy sales data** using two powerful tools: **Microsoft Excel** and **Power BI**. The objective is to derive actionable insights from sales performance, customer behavior, and operational trends through interactive dashboards.

Both dashboards are built on the same dataset to demonstrate cross-platform analytical capabilities and visualization techniques.

---

## 🎯 Objectives

* Analyze overall sales performance
* Track order trends (daily, weekly, monthly)
* Identify top-performing cities, states, and restaurants
* Compare food category performance (Veg vs Non-Veg)
* Evaluate customer satisfaction through ratings

---

## 📊 Key Metrics

* 💰 Total Sales: ₹53.01M
* 📦 Total Orders: 197.43K
* ⭐ Average Rating: 4.34
* 🧾 Average Order Value: ₹268.51
* 👍 Rating Count: 5.59M

## 📈 Dashboard 1: Power BI

### 🔹 Features

* Interactive slicers (City, Food Type, Restaurant)
* Monthly, Weekly & Daily Sales Trends
* Sales breakdown by Food Type
* Top Restaurants Analysis
* State-wise Sales Performance



## 📊 Dashboard 2: Excel

### 🔹 Features

* Dynamic charts using Pivot Tables
* Monthly, Daily & Weekly Trends
* Sales by State (Map Visualization)
* Top Cities & Category Analysis
* Quarter-wise Sales, Ratings & Orders

## 🔍 Key Insights

* 📌 **Karnataka** generated the highest sales (~₹5.5M)
* 📌 **Non-Veg category** dominates (~64% of total sales)
* 📌 **Top Restaurant:** KFC (~₹4.2M sales)
* 📌 Sales show consistent growth after February dip
* 📌 Weekends generate slightly higher revenue
